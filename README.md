# GTA-AVT

GTA面向主动脉血管树分割的实现：**预测局部解剖属性，以条件计算适配特征融合，再用高斯几何监督强化成熟分割网络。** 普通训练与推理都由CT预测属性；标注几何只用于训练监督及评价。

## 方法与阶段

P为属性预测网络，输出连续血管支撑及物理尺度；S包括编码器、解码器、属性融合、条件路由及分割投影。四分支有界条件融合保留历史GTA算子结构，并针对AVT的血管尺度与稀疏前景定制属性消费。

| 阶段 | 成功更新预算 | 主要训练范围 |
|---|---:|---|
| 属性预训练 | 30k | P |
| 底座建立 | 20k | P＋S，中性条件 |
| 底座长训练 | 30k | P＋S，主分割、深监督及属性辅助 |
| 条件适配 | 10k | 固定P及底座主干，局部条件融合与分割投影 |
| 高斯头预热 | 2k | 固定P/S，仅新高斯头 |
| 高斯联合强化 | 20k | 固定P，整个S＋高斯头 |
| 平衡微调 | 10k | 固定P，整个S＋高斯头，较低学习率 |

主分割保留Dice及前背景比例BCE。TRAIN采用病例等权和分阶段的血管／细血管／分叉／边缘／高强度背景／均匀视野取块；取块来源比例与实际前景体素比例分别记录。

新版高斯头为 `Sigmoid(Conv3d(Z))`，读取最终两通道分割logits。原始高斯场在整病例有效域归一化到0至1，再映射到0.5至1；目标定义和输出范围配套。几何损失与主分割损失共同反传到S，P保持固定，BN运行统计保持固定。

本次直接继承既有主线AR条件适配结束的P/S，不重做前面的属性、底座和条件适配。新头2k预热只准备一次；之后有／无GDF两支从同一状态分别执行20k＋10k，构成最小匹配对照。旧四支完成原配方及整例评价，保留为独立版本记录。

## 复现范围

完整源分支提供安装说明、配置、训练／推理／评价入口及测试。不同版本分别使用独立源目录、配置、目标覆盖层、运行目录和结果身份；原有训练不会在运行中替换配方。训练权重、凭据、原始CT和标注不随本仓库发布。

本轮固定36例TRAIN、8例VAL，seed20261032，输入128³、batch2。核心消融先于重复种子；尚不据单种子结果声称种子稳定性或zero-shot。历史TEST记录属于其当时固定方法，不能用于当前版本选择。

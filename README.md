# GTA-AVT v1.1

**算法开发版：可靠性调节的局部条件融合与高斯几何监督。**

本项目交付方法代码，不附带v1.1训练权重，也未开展v1.1数据集训练。
v0.1与v1已有成绩是设计依据，不是本版本性能。三个核心均实际保留：

1. **属性**：CT预测血管支撑分数、连续log半径均值和误差尺度；几何可测性仅作监督掩码。
2. **条件计算与融合**：保留v0.1四分支、576系数的局部有界路由，取消低召回的硬A入口。
3. **高斯场**：共享分割特征上的Gaussian辅助头，前景/背景平衡损失，渐进参与局部适配。

完整定义与论文表达见 [中文方法](docs/METHOD_ZH.md) 和 [English method](docs/METHOD.md)。

## 结构与训练路线

```text
CT ── 属性网络P ── 支撑v、尺度均值mu、对数方差s ── 条件坐标
           └──── 多尺度属性特征 ─────────────────────┐
CT ── 分割底座G0 ── 特征融合 ── 局部条件残差路由 ── 共享F32
                                                     ├─ 分割头
                                                     └─ 高斯场头
```

尺度可靠性为 `relu((1-exp(s))/(1+exp(s)))`；尺度坐标为
`v * reliability * clamp(mu,-4,4)`。这是一项相对TRAIN参考方差的调制规则，
不宣称不确定性已校准。正常分割前向只接收CT，不接收标签、中心线或有效性掩码。

| 阶段 | 可训练部分 | 作用 |
| --- | --- | --- |
| pretrain | 属性网络P | 学习支撑、尺度及误差尺度；未知尺度弱先验约束 |
| base | 分割网络，P及路由系数固定 | 建立共同的中性条件分割底座 |
| gdf_head | 仅高斯头 | 预热辅助头，不扰动底座 |
| local_adapt | 四分支、融合投影、576系数、分割投影、高斯头 | 115491参数局部适配，主干及全部BN/Dropout固定 |

局部阶段卷积/投影学习率1e-4、门控1e-3；先爬坡条件增量，再延迟加入Gaussian损失。
默认预算见配置，是未来研究的起点，不代表已验证最优。

## 从原始数据运行

建议Python3.8以上、PyTorch1.11以上；项目导入不会启动训练。

```bash
python -m pip install -e .
python -m gta_avt index --root /path/to/AVT --split-file configs/split_avt_20261022.json --output cases.json
python -m gta_avt prepare --cases cases.json --output cache
python -m gta_avt pipeline --config configs/pipeline.json
```

`prepare`从TRAIN计算属性及高斯归一化统计，同时为VAL准备真实前景高斯目标。
没有有效几何的位置保持未知；TEST不进入训练统计或检查点选择。
`import-cache`可显式导入已有缓存，但旧缓存必须重新生成本方法支撑目标及完整VAL高斯场。

流水线从同一已选底座和高斯头预热检查点分别运行：

| 组别 | 属性条件 | 高斯损失 |
| --- | --- | --- |
| C0 | 中性坐标，保留相同P特征与容量 | 0 |
| AR | 预测支撑与可靠尺度 | 0 |
| C0_GDF | 中性坐标，保留相同P特征与容量 | 渐进到0.1 |
| AR_GDF | 预测支撑与可靠尺度 | 渐进到0.1 |

`V_only`是可选支撑条件诊断，不在默认四组矩阵中。四组不独立识别属性预训练相对普通骨干的收益。

## 推理、评价与验证

```bash
python -m gta_avt infer --config configs/infer.json
python -m gta_avt evaluate --config configs/evaluate.json
python -m pytest -q
```

训练与推理默认都使用相同P的CT预测路径。属性覆盖参数只供明确诊断，不在正常流水线中使用。
训练/推理使用相同128立方区块；推理为重叠滑窗，恢复原物理空间。Gaussian窗口融合与GDF辅助监督是不同机制。

检查点选择以固定VAL样本的分割Dice优先、BCE平局判定；GDF前景/背景误差与有效数量单独报告。
原生评价对NIfTI文件头精度仅接受通过原CT认证的精确float32量化，不重采样或修改预测体素。

单元测试使用合成数据检查属性语义、未知掩码、阶段冻结、条件响应、GDF梯度路径和数据/检查点来源。
工程测试不能替代真实数据Dice、误检漏检、差病例及配对消融结果。

本次实际CPU核验：49项通过，1项因Windows不允许创建符号链接而跳过。包括完整模型32立方输入的前向、反向和冻结状态检查；未运行CUDA或128立方显存测试。详见 `ENGINEERING_QA.json`。

## 实现边界

- 不自动下载原始数据、不自动连接服务器、不自动发布结果。
- 不将v0.1或v1权重静默转换成本版本；新增属性通道和训练语义要求显式新训练。
- 不声称Dice、拓扑、零样本或方差改善已获验证。
- 原气道GTA保持其原模型和实验身份；统一的是属性条件化特征适配思想。
- 第三方卷积/融合原语及许可证保留在 `gta_avt/vendor/`。

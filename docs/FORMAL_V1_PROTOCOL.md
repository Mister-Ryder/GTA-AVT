# Fixed GTA-AVT-v1 initial formal experiment

Declared 24 October 2026, before any v1 optimizer training on AVT.

- Three complete independent seeds: 20261030, 20261031, 20261032.
- One seed per server; two RTX 4080 environments and one vGPU environment.
  Physical devices differ. Report the vGPU block separately and retain all seeds.
- Reuse the existing 36 TRAIN / 8 VAL split. Do not tune or select on TEST.
- Data: original verified 1mm CT/mask/native-EDT geometry; CT-only padding validity;
  new TRAIN-only case-equal radius moments and applicability prior. Reuse the
  completed all-centre Gaussian target and its frozen TRAIN RMS after identity checks.
- Attribute predictor: independent random initialization, BCE applicability plus
  emitted-only standardized-radius MSE, 20,000 successful AdamW updates, lr 0.0003,
  polynomial decay, batch2, patch128, paired augmentation. VAL every1,000 updates.
- Select the lowest validation-loss checkpoint among those satisfying the fixed
  prerequisite report (`best_ready.pt`): all VAL cases have target variation and
  nonconstant predicted hard-A radius support; case-mean applicability BCE and
  radius MSE beat TRAIN constants; case-centered radius error beats a constant.
  These checks are fixed before training. Report all diagnostics.
  If none qualifies, stop that seed and report the failure; no automatic rescue.
- Freeze all predictor parameters and BN statistics. S starts randomly, common
  C0/alpha0 warmup10,000 successful updates, lr0.0003.
- Clone the final common warmup for C0 / A_only / AR / AR_GDF. Each arm receives
  5,000 full-S updates, lr0.0001 and polynomial decay; alpha ramps over1,000 updates.
- Same predictor, feature inputs, trainable adapters, architecture, seed, sample
  sequence, successful-update budget, Dice+BCE objective and validation procedure.
  Deep supervision weight0. All arms retain an identical GDF head; only AR_GDF
  uses Gaussian MSE weight0.1. No new attributes, backbones or airway experiments.
- Segmentation checkpoint selection excludes the GDF loss, using the same
  sampled-VAL Dice+BCE criterion for every arm. Retain both best and final states.
- Primary result: CT-only whole-volume/native-space VAL at the common final
  update, patch128/overlap0.5/batch2/threshold0.5. No label-derived inference ROI.
- Report every case and seed: Dice, precision/recall, FP/FN, clDice and centreline
  precision/recall, and native physical EDT radius<=2mm centreline recall with its
  support count. Summarize mean, population SD, minimum and worst20% case mean.
  Report pairwise C0→A_only, A_only→AR, C0→AR and AR→AR_GDF changes objectively.
- Attribute-feature learning is shared by these controls; this experiment does
  not isolate its effect against a separately trained segmentation-only network.
- Preserve actual failed prerequisites, numerical failures and negative scores.
  No mid-course weight/schedule/attribute search or endpoint rescue in this round.

Engineering verification and execution-only data placement/parallel loading may
be repaired before optimizer training, with the change recorded. Training source
and scientific configurations are frozen at dispatch. Data loader worker count
changes throughput only; indexed samples and update budgets remain identical.

Earlier exploratory AVT oracle results are distinct experiments. The current
full v1 results must be generated by this pipeline and must not inherit their
performance labels. Case IDs are not confirmed independent patients, and these
VAL cases have already appeared in development.

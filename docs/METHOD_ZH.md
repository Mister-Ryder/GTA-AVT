# GTA-AVT v1.1：可靠性调节的局部条件融合与高斯几何监督

本版本是新的算法实现，尚无 v1.1 数据集训练结果。v0.1、v1 的实验是设计依据，均不改记为本版本成绩。

## 方法主张

GTA 用 CT 预测的解剖状态调节局部特征处理方式，并以几何场监督约束共享表征。v1.1 保留属性、条件计算与融合、高斯场三项核心，以成熟底座上的局部条件增量实现适配。

核心修正是区分血管支撑、局部尺度、尺度估计可靠性、尺度监督有效域。不能继续把它们合并成一个二值 A。

这条路线延续v0.1的局部适配结构，而非继续把整个分割网络与新条件同时重学。v0.1给出了局部条件适配的可行线索；v1说明预测条件进入实际消费者时仍可能失效。因此，本版本优先修正“属性是什么、何处可信、怎样改变特征”，再用阶段训练限制新增机制对共同底座的扰动。

| 设计问题 | v1.1的决定 | 原因 |
| --- | --- | --- |
| 什么属性与血管异质性直接相关 | 使用物理尺度，不以根节点深度替代尺度 | 深度不能保证血管粗细，连续半径有直接几何定义 |
| 何处进行适配 | 连续血管支撑分数 | 几何可测性只说明监督是否可靠，不能代表所有值得分割的位置 |
| 尺度不可信时怎么办 | 缩小尺度条件增量，保留支撑适配与静态通路 | 不让未知尺度强迫选择错误分支，也不禁止该位置参与分割 |
| 条件究竟改变什么 | 同一局部四分支的相对组合 | 不增加一个与原融合脱节的后处理模块 |
| 高斯场怎样参与 | 对共享特征施加平衡几何监督 | 避免仅训练一个与分割适配无关的辅助输出头 |

这里的“层级”是信息层级：血管支撑→局部尺度→尺度信息的可靠程度；不是重新制造缺乏解剖依据的离散血管等级。

## 属性定义

主要属性仍为原生物理 EDT 在中心线处的半径代理：

\[
z_R^*=(\log(r/\mathrm{mm})-\mu_{\rm TRAIN})/\sigma_{\rm TRAIN}.
\]

原几何程序的可测性改为损失掩码 M_R。分叉、截断、最近节点歧义处保持未知，不是半径零，也不凭这个掩码禁止分割特征适配。

CT 属性网络输出三个通道：支撑 logit、尺度均值 mu_R、尺度对数方差 s_R。支撑目标是半分辨率单元内的实际血管占据率，填充区排除，以 Dice+BCE 学习支撑分数 v。该分数不宣称已经概率校准。

可靠尺度域采用病例等权异方差回归：

\[
L_R=\operatorname{Mean}_i\operatorname{Mean}_{M_{R,i}}
\tfrac12[e^{-s_R}(\mu_R-z_R^*)^2+s_R].
\]

不可测真实区域使用小权重 KL[N(mu_R,exp(s_R)) || N(0,1)] 正则。未知前景和背景分别归一化，再按病例平均。标准正态是 TRAIN 标准化参考先验，不是给未知位置伪造测量真值。

消费者采用：

\[
q_R=\max\{0,(1-e^{s_R})/(1+e^{s_R})\},\quad
c_V=v,\quad c_R=vq_R\operatorname{clip}(\mu_R,-4,4).
\]

估计误差尺度不优于参考先验时，尺度增量归零，支撑分支仍可工作。截断界是可配置数值保护，不是解剖类别。异方差不自动等于校准不确定性，这项对应关系需要后续检验。

## 条件计算与融合

| 部分 | 具体结构 |
| --- | --- |
| 属性网络P | 四级3D卷积编码器32/64/128/256通道，多尺度特征融合；输出半分辨率的支撑、尺度均值、尺度对数方差 |
| 分割底座G0 | 四级编码器32/64/128/256通道，三级解码器128/64/32通道；保留原特征融合与属性特征连接 |
| 局部条件适配 | 在64通道解码特征处，融合128通道属性特征；四个64→16卷积分支，拼接后64→64投影 |
| 输出 | 多尺度融合及属性引导形成共享32通道特征；32→2分割投影、32→1加Softplus的高斯投影 |

冻结的属性编码器同时提供属性和多尺度特征。先融合分割特征与属性特征得到 B，再使用 v0.1 的四个卷积分支及 dilation=(1,1,2,3)：

\[
g_j=\tanh(b_j+u_jc_V+w_jc_R),\quad
F=F_0+\alpha g_1D_1+\alpha(1-|g_1|)(g_2D_2+g_3D_3).
\]

F0、D1、D2、D3 沿用原四分支及融合投影构造。b/u/w 共576个系数，零初始化。四分支等效系数位于[0,2]且和为4；这不是特征能量守恒、Dice或拓扑保证。

具体地，四分支输出记为h0至h3，投影矩阵W按输入通道分为W0至W3，k=(1-1/3)(1+0.1/3)。则F0=B+k[ΣWi hi+bW]，D1=k(-W0h0-W1h1+W2h2+W3h3)，D2=k(W0h0-W1h1)，D3=k(W2h2-W3h3)。三个方向分别调节分支组之间以及各组内部的相对贡献。分支不是预先指定的解剖类别，其任务分工由学习形成。

静态对照使用相同特征、容量及偏置 b，仅令 cV=cR=0。没有 A>=0.5 的部署开关，监督掩码不进入分割前向。正常训练与推理均使用 CT 预测属性，标签只用于损失和评价。

## 高斯场监督

保留全病例中心线、物理半径和 TRAIN 固定尺度构建的目标：

\[
G^*(x)=Y(x)s_{\rm TRAIN}^{-1}\log\left(1+\sum_c
\exp[-\|x-c\|_{\rm mm}^2/(2r_c^2)]\right).
\]

最终共享32通道特征分别连接分割头与 Softplus 高斯头。高斯损失先在每例内分别平均有效前景和背景，再平均实际存在区域，最后病例等权。这样大背景不能仅靠拟合零值淹没血管内部几何监督。

VAL也准备真实前景高斯目标，归一化统计仍只来自TRAIN。未知域排除并报告支持量，不再把仅有背景的损失当作前景高斯场质量。局部阶段高斯梯度通过共享特征、冻结层的输入 Jacobian 影响活动路由，而非只拟合断开的头。

## 分阶段训练

1. 独立训练属性网络，直接检查支撑重叠、召回、尺度误差与可靠性，随后冻结参数和BN。
2. 随机初始化分割网络，以中性条件训练共同底座G0。
3. 冻结底座，仅预热高斯头，减小随机辅助头对成熟分割的初始扰动。
4. 冻结主干、其他融合层及全部BN/Dropout，仅更新四个局部分支、融合投影、576个系数、最终分割投影及高斯头，共115491个参数。

局部阶段恢复v0.1的分组学习率：卷积/投影1e-4、门控1e-3。先爬坡条件增量，再延迟、渐进加入高斯损失。主目标为 Dice+BCE，Gaussian权重独立配置。

分割检查点以固定验证样本的Dice为首要标准，BCE用于平局，高斯损失不替代主指标。高斯头预热不作分割收益声明。默认阶段预算是明确研究起点，不声称已最优。

## 统一论文表达与验证范围

统一主张是：解剖属性描述局部任务状态；条件计算控制相对共同底座的特征增量；几何场监督约束共享表征保留树状结构。原气道的离散属性及原适配模块保留真实实验身份，不能改写为已检验本版本新算子。

统一表达可以写为z=P(x)、f'=f+Δ(f,z)，以Lseg+λ(t)LG共同学习分割表征。条件z描述当前局部二分任务的状态，Δ描述这种状态应如何改变特征处理。气道使用其原有的离散解剖属性与适配器；主动脉使用支撑、连续尺度和可靠性调节的有界局部融合。统一的是“按解剖状态调整分割计算”的原则，具体属性和适配算子随解剖对象变化。阶段训练属于优化方法，不需要重写原气道实验为本版本流程。

默认最小条件×高斯对照为 C0、AR、C0_GDF、AR_GDF；V_only 可用于区分支撑和尺度。四组共享属性网络、底座、高斯头预热权重、样本顺序及局部预算。这四组不独立识别属性预训练相对普通骨干的收益。

v1.1预期通过可预测支撑、可靠尺度调制、有限局部更新和有效几何监督改善分割。这是待验证方法假设，代码实现不能替代后续Dice和配对消融结果。

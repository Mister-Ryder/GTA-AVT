# 局部尺度条件如何调节原分支融合

在 `code/faithful_model.py` 的 `soft_structure` 中，记原基础融合为
\(B\)，四个卷积分支拼接后的64个通道为 \(h_k\)，原1×1融合卷积
的权重、偏置为 \(W,\beta\)。令
\(c=(1-p_{empty})(1+0.1p_{junction})\)，则原算子为

\[
F_{0,i}=B_i+c\left(\sum_k W_{ik}h_k+\beta_i\right).
\]

新残差使用同一权重：\(D_i=c\sum_kW_{ik}s_kh_k\)，其中前两个
16通道分支的 \(s_k=-1\)，后两个为 \(+1\)。它们分别具有
1/1/2/3的膨胀率，只代表不同感受野，不预设为解剖专家。
令实际消费的支持轴为 \(A\)，尺度轴为 \(z_R\)，并令

\[
g_i=\tanh(b_i+v_iA+w_iz_R),\qquad F_i=F_{0,i}+\alpha g_iD_i.
\]

在实数算术或统一精度下，展开即

\[
F_i=B_i+c\beta_i+
c\sum_k(1+\alpha g_i s_k)W_{ik}h_k.
\]

因此，条件改变原有局部/上下文响应的贡献，不需新增专家卷积。
当 \(\alpha\in[0,1]\) 时，括号系数位于 \([0,2]\)，但它不是凸概率
混合：系数不归一化，且 \(W\) 与特征都可带符号。开放原分支梯度改变
可学习的响应基，不改变上述算子形式。

**精度边界：**实际AMP中原形态投影以FP16计算，\(D\) 则显式
FP32；上式是代数解释，不是AMP逐位等价证明。实际核验通过的是
零适配器起点与原模型的输出逐位等价。

这是GTA“属性→条件→特征融合”的一个具体实例，不是普适定理、条件
计算的新颖性证明或效果保证。当前属性来自部分GT oracle，不能据此
声称CT预测条件可部署或GTA已获有效验证。

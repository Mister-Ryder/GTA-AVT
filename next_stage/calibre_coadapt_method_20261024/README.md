# 局部管径 oracle 的有限共适应试验

状态（2026-10-24）：三组正式试验已完成。[完整结果](../../reports/calibre_coadapt_TRAIN_20261024/readout_zh.txt)保留全部种子、对照、病例、支持与停止判定。此处为运行前方法说明；GT oracle 结果不等于 CT-only GTA 验证，不授权自动后继。

此前边界属性在固定 GAAM gain、SAAM gain 和固定 context 方向上的诊断均未通过。它们约束的是既有特征、既定方向及当前损失导数；极低的切线解释能量不能作为所有共同学习方法的必要失败条件。因此停止继续更换冷算子下的属性定义追阳，另立一次有固定预算的共适应能力试验。旧阴性结果不被救回。

本轮同时改变了**属性定义**与**消费端学习方式**，不能把跨轮差异归因于其中某一因素。新一轮内部三臂则具有相同模块、参数清单、初始前向、样本顺序、优化器及预算，仅条件信息不同：

| 臂 | 支持条件 | 管径条件 |
| --- | --- | --- |
| C0 | 常量零轴 | 常量零轴 |
| A_only | 固定 GT 几何测量支持 A | 零轴 |
| AR | 与 A_only 完全相同的 A | 同支持内的标准化 log-radius |

C0是常量条件对照，保留共同原 GTA 特征/融合路径，不是无GTA网络。

R 为原生物理 EDT 在重采样 Lee 骨架节点处的半径代理，使用 `log(radius_mm / 1 mm)`。它不是临床管腔真值，也不保证空间连续。仅非分叉、半径有效、半径支持球完整落在实际 patch CT 可见域内的可识别最近节点提供数值；其余保留 unknown 状态，消费轴中性填零，不解释为半径零或背景负标签。A 是该几何测量的可用支持，不是 CT 预测，也不是血管存在概率。没有用 GT 背景证书补全支持。

SAAM 实际输出为 64 通道、64³格点（128³输入的名义采样点为 `.5 + 2u`，不是实际感受野中心）。固定原四分支的 `[-,-,+,+]` 对比经原 1×1 权重形成 `D_theta`，保留原均匀三分类概率因子；不把分支称为已验证的解剖专家。

```text
zR = A * (logR - mu_fit) / sigma_fit
F  = F0 + alpha * tanh(b + v*A + w*zR) * D_theta
```

三个 64 维向量 b/v/w 全零初始化。所有臂共同训练原 SAAM 投影 4,160 参数、原最终分割投影 66 参数及 192 个门参数，共 **4,418**。其余参数冻结；全部模块保持 eval，BN/Dropout 行为固定。原 1×1 权重在 F0 与 D_theta 中均允许学习，最终分割投影也学习，因而不是只给冷算子增加一个标量读出。

4,418表示相同的参数注册与优化器清单，不表示三臂函数容量完全相同：C0的v/w梯度为零，A_only的w梯度为零，实际QA已核验。因此还必须比较同一最终AR权重下的正确与错配半径，不能仅凭额外条件系数或训练收益判断半径语义有效。半环干预保持数值多重集，但会改变空间相关性，不是抽象的纯语义开关。

本轮没有属性辅助损失，原有分类特征由三臂共享。Oracle条件把消费端能力与预测器误差暂时分开；它不能估计属性学习本身的贡献。后续若转为CT预测条件，仍须独立预训练预测器，并在固定预测器下重新隔离动态消费贡献。

`mu_fit/sigma_fit` 只取 FIT24：每例汇总原 16 槽中 A=1 的 logR 一、二阶矩，再对 24 例等权合并。每例必须有支持且总体方差为正；不加 epsilon，不用 PROBE12 调参。

每组 seed（20261030、20261031、20261032）在同一设备上串行运行 C0→A_only→AR；三组预锁，不选最好 seed，首组失败不得靠另组救回。各组重复同一批病例，不能当作新增36个盲验证病例。每臂固定 **2,000 次成功更新**，128³/B2，FIT24 病例与 16 槽均匀采样，无增强。AdamW：共同投影学习率 1e-4，门参数 1e-3，weight decay 1e-5；仅原主输出 Dice+BCE，无 DS/GDF/属性辅助损失。`alpha=min(1,step/250)`。只读最终端点，不按 probe 选 checkpoint 或延长预算。

正式评价保留原 PROBE12 的全部 16 槽；主要指标仍是已知非空 GT-jitter 槽0–7，先 patch 等权再病例等权。AR须优于两对照的平均 Dice，并且 clDice、中心线召回、细管径召回和自身最差两例 Dice 不下降。另一项必要证据是**同一最终 AR 权重**：在每个 patch 自身 A=1 的展开索引内，将 R 固定半环移动 `floor(N/2)`，严格保留自身 A、支持位置和 R 多重集。正确对应相对错配须平均 Dice 至少 +0.1pp、至少8/12例为正且12例支持。门槛保持，不将它们称为统计显著性或 GTA 的理论必要条件。

若固定候选通过，才考虑属性预测器独立预训练及 CT-only 条件迁移；那仍需新受控验证。若失败，停止本候选，不改窗口、阈值、seed、gain或预算救援。Oracle只是理想化条件的利用能力测试，**不是部署方案、不是严格性能上界，也不是 CT-only GTA 成功**。已训练 backbone 与开发复用 TRAIN、重叠 patch 和未核实患者独立性均限制泛化解释；没有 VAL/TEST 使用。

CondConv 将输入相关路由与卷积响应共同学习，并指出常量路由退化为静态卷积容量；这支持检验共同适配的必要性，但不保证本任务受益。[CondConv, NeurIPS 2019, §3–4](https://proceedings.neurips.cc/paper/2019/file/f2201f5191c4e92cc5af043eebfd0946-Paper.pdf)

Dynamic Convolution 讨论注意与卷积核共同优化的困难，并研究早期近均匀注意。本试验没有照搬其温度调度或性能结果；这些既有工作也意味着一般条件计算本身不能直接作为 GTA 新颖性已获证明的依据。[Dynamic Convolution, CVPR 2020, §4](https://arxiv.org/pdf/1912.03458)

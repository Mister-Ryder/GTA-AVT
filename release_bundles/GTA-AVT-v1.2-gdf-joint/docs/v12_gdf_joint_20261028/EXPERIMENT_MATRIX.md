# 版本与对照关系：保留旧结果，验证修订后的高斯监督

日期：2026-10-28。现有四支实验保持原配方完成及整例评价，之后才启动修订后缀。下文中的“待完成”表示状态，不预判性能。

## 版本对应

| 版本／对象 | 属性与底座 | 条件适配 | 高斯监督 | 能回答的主要问题 |
|---|---|---|---|---|
| v0.1阶段实现 | 已有可用底座及相应属性消费设置 | 成熟底座上的局部适配 | 该阶段未完成本次完整高斯联合路线 | 提供局部条件消费可学习的阶段证据；不能推出任何后续训练配方必然有效 |
| 正式v1 | 独立属性预训练、共同分割热身及固定尾段 | 与对应静态条件对照比较 | 当时的并列头／训练配方 | 保存三种子客观结果；与v0.1的起点和训练谱系不同，不能只按版本号比较 |

`gdf-joint-r3`同时恢复接点、目标范围及训练范围，是一套成组的方法修订。新旧结果的差异不能被拆解成某一个改动的独立因果效果；本轮不新增冻结范围或接点网格。

## 已运行的旧2×2

四支从同一所选P/S底座出发，各自执行42k尾段：条件10k＋头预热2k＋局部几何20k＋局部精修10k。

| 旧分支 | P及属性特征融合 | 消费预测动态条件 | geometry／refine中GDF监督S | geometry／refine范围 |
|---|---|---|---|---|
| C0 | 保留 | 否，可学静态门 | 否 | 局部 |
| AR | 保留 | 是 | 否 | 局部 |
| C0_GDF | 保留 | 否，可学静态门 | 是 | 局部 |
| AR_GDF | 保留 | 是 | 是 | 局部 |

有／无GDF组都经历头预热；“无GDF”准确指后续不将几何损失用于更新共享分割路径。静态C0并未删除属性预测器或属性特征融合，总注册参数相同；但静态组部分动态斜率无数据梯度，不能声称有效自由度严格相同。

这些运行采用相同科学配方、父权重、种子与预算，但AMP及CUDA非确定性使实际跳过更新和贡献梯度的区块流可能不同，不能称为逐位相同执行。最终按逐例指标及配对差值报告，不把中途区块波动解释为高斯因果。

| 配对 | 检验内容 | 不应扩展成的结论 |
|---|---|---|
| AR − C0 | 不加GDF时的动态条件贡献 | 属性网络相对无属性骨干的独立贡献 |
| AR_GDF − C0_GDF | 局部GDF存在时的动态条件贡献 | 证明全S高斯联合监督有效 |
| C0_GDF − C0 | 静态条件下的局部GDF贡献 | 所有高斯接点／训练范围的一般结论 |
| AR_GDF − AR | 动态条件下的局部GDF贡献 | 新版全S联合训练的匹配对照 |

## 修订后的最小匹配对照

只新增以下两支，不增加新种子、额外普通骨干、接点候选或范围网格。

| 项目 | AR：全S、无GDF | AR_GDF：全S、有GDF |
|---|---|---|
| 起点 | 同一主线AR `condition/last` | 完全相同 |
| 新头初始化与2k预热 | 共享一次准备后的状态 | 完全相同 |
| P | 固定 | 固定 |
| S有效分割路径 | 全部参与主分割优化 | 同范围参与分割＋高斯优化 |
| BN运行统计 | 固定 | 固定 |
| 主目标 | 原Dice＋比例BCE | 完全相同 |
| 条件、采样、学习率、成功更新预算 | 相同 | 相同 |
| 额外GDF项 | 0，仅保存诊断 | 经TRAIN校准的既定倍率日程 |
| 后缀预算 | 共享头2k＋本支20k＋10k | 共享头2k＋本支20k＋10k |
| 主要评价 | 固定原生VAL8、最终last | 相同 |

共享预热后，两支各30k分割联合／对照更新，总新增训练计算62k。共同预热期间S固定，所以它不使无GDF组提前接受几何梯度。新无GDF支不可用旧局部AR的最终结果替代：开放整个S本身增加了学习机会，必须给予匹配控制。

## F底座读出的位置

F为所选 `base/best_ready` 的零新增训练原生整例评价，处于条件、高斯头、几何强化及精修之前。已得到Dice93.055603%、病例总体SD2.976870个百分点。

F到任一最终模型之间包含条件适配及额外训练，能够显示系统的阶段表现，**不能作为纯组件消融**。F的参数规模与文献强方法可作为不同协议的性能／规模背景，不能代替属性因果消融，也不能据此声称同条件优胜。

## 结果文件与报告次序

每个端点保留源版本、父检查点身份、成功更新数、最终检查点身份、评价协议和逐例指标。旧四支与新两支分别汇总，不混成同一2×2或跨版本相减。

1. 先报告原生病例等权Dice及逐例配对差值。
2. 再报告precision／recall、clDice、细中心线召回、最差病例和病例分散度。
3. 解释阶段损失及高斯误差时，区分目标定义和训练范围；不同目标的总loss不能直接比较。
4. 保存负结果、失败和异常，不用新版本覆盖旧记录。

本轮为单种子核心验证。病例间标准差不是种子方差，不据此声称随机初始化稳定性、zero-shot或普遍泛化优势。TEST不参与本轮方案调整。

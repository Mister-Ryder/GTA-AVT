## 比较了什么

三臂分别为常量零条件 C0、仅几何可测支持 A_only、同一支持加连续 log 半径 AR。C0保留共同 GTA 特征与融合路径，不是“无GTA网络”。三臂从相同7406状态出发，用同一 FIT24 采样计划各训练2000步；只学习原融合/末层投影4226参数和192条件系数，其余冻结且所有模块保持eval。没有属性辅助损失，只用原主输出Dice+BCE。

A/R由稀疏GT几何流程直接给定，R是native-EDT半径代理，A本身也携带几何信息；AR−A_only只隔离已给定支持后的附加数值贡献。未知位置消费中性值，不变成背景或半径0。这是TRAIN能力检查，不是CT属性预测、严格上界或部署结果。FIT24/PROBE12来自持续复用的TRAIN36，共同权重已经见过这些病例；没有VAL/TEST使用。

## 采样层风险与下一步唯一因素

CT_uniform已知非空层中，AR−A_only的细支召回为 **−0.919774/−2.143555/+1.621963pp**；seed31 clDice也为−0.196164pp。该层细支只有10例有支持（clDice和中心线召回为12例），不能补0或切换主口径掩盖。这不是所有粗细指标必然冲突；它提示主要GT-jitter收益没有自动迁移到另一固定采样层。FP/FN也存在交易：seed31主要层AR相对A_only减少FP约92.48、却增加FN约41.21个/采样区块；不能把所有Dice提升都称为覆盖提高。

下一独立候选只把原四个SAAM分支从冻结改为共同学习：共享114882参数+192门参数=115074，三臂都从共同初态重新匹配训练。分支在原F0及context对比路径均可反传；A/R、标准化矩、2000步、损失、学习率、alpha250和原门槛不变。它检验固定h表示是否限制共适配，不宣称已找到瓶颈，也不以更大容量本身宣布GTA有效。

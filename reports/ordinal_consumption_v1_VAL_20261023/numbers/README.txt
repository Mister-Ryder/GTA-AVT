Numerical recomputation package for one frozen ordinal GTA candidate.

Run: python recompute.py --package . --check
The script uses only the Python standard library. Default is inert.

There are48 native case-prediction records:2 arms x8 cases x3 blocks.
They reuse the same8 development cases and common original warmstart; they
are not48 independent patients. Blocks differ in finetuning/augmentation
seed and platform. No pooled patient or independent-pretraining claim follows.

Each block contains576 fixed TRAIN derived condition/response records.
No image, mask, volume, patch coordinate, checkpoint, machine identity,
credential, command or private execution path is included. Channel gains,
five-class probabilities and confusion counts are derived numerical data.

Pure frozen arithmetic functions are copied with canonical AST identities.
Both correspondence interventions, null support and the numerical-null
safeguard are retained. All utility and mechanism rules are unchanged.
Two nonnegative descriptive variance fields alone allow at most two binary64
ULPs of cross-platform comparison rounding, with zeros/positivity/types exact.
Every other value, effect, count, consumed condition and scientific gate is exact.
The original protocol and numerical-null addendum bytes are included.
The A/B gates are recomputed before C is interpreted; terminal failure
cannot be rescued by a positive C result. No new threshold, fit, confidence
interval, significance test or experimental selection is introduced.

This package verifies released derived numbers and arithmetic. It does not
rerun segmentation or independently prove the private execution provenance.
Case SD is case dispersion, not training/inference variance. No pristine
patient, zero-shot, held-out source, clinical-margin or significance claim.
Both arms retain the same attribute supervision; utility alone is insufficient
to establish useful dynamic conditions. Read the frozen gates and full outputs.

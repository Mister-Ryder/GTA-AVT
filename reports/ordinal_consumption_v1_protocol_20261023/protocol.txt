Question and single change
The old7406 classifier already predicts the original five class masses. Consume
c_ord=p1+(2/3)*p2+(1/3)*p3, the mean of cumulative nonempty masses below2/4/8mm.
This is an ordinal fineness score, NOT expected physical radius or clinical diameter.
Empty p0 and >8mm p4 both contribute0, so the scalar is not fully identifiable anatomy.
The same uniform [.2]*5 reference maps to c=.4. G0 still has original q0=s0=.2.
Keep the same256 zero w/b parameters, GAAM site, labels/head/aux losses, old7406
warmstart,2k successful updates, alpha0/ramp500,128/B2, poly1e-4 and GDF0.
Do not normalize, clip, add temperature/gain, change labels/local head, or use K weights.
This is one named consumption-map change; old fine-score controls/results remain intact.

   case MSE values strictly better, and each of the three source macro MSEs nonworse.
   Conditional ordinal MSE must also be nonworse than its fit-mean baseline.
3. >=10/12 probe cases, and>=3/4 in each source, have GT population variance>=1e-6
   and predicted c population SD>.01. At least8/12 within-case Pearson r values
   are positive; centered-then-concatenated Pearson r>=.3. Report case-mean r too.
   Positive correlations count only the declared informative cases; the required
   count remains8 of the original12, not a reduced selected-case denominator.
   Undefined correlations remain null and do not count as positive.
4. At the same existing55,294 TRAIN anchors, compare stored native-derived EDT
   radii with physical EDT of the FULL cached1mm case mask. Never re-skeletonize
   or compute EDT on truncated patches. Keep anchor membership/denominators fixed.
   For the same probe12 FG patches, N=equal-case mean squared native-vs-cached
   ordinal target difference; V=equal-case population within-case native target
   variance. Require V>0 and N/V<=.25. This is a signal-to-cross-grid-discrepancy
   budget rule, NOT annotation uncertainty or clinical validation. Report all36,
   node/mm errors, bin transitions and support. No extra absolute MAD threshold
   or fake half-mm raster dilation. Missing/invalid anchors fail integrity.
5. Each actual platform passes128/B2 AMP QA with correct source/runtime/input

   b/w gradients/updates. QA alpha1 is branch coverage only. Exact common initial

All listed gates are conjunctive. A fail stops this named candidate before training.

Completion and stop
Only prerequisites + A/B individual utility/mechanism passes + locked C same passes
support the narrow reproduced dynamic ordinal-condition claim. Auxiliary gains,
nonzero parameters or synthetic QA alone do not complete the goal. These numeric
margins are prespecified opportunity-cost rules, not significance/clinical margins.
Failure means stop this named candidate at its immutable endpoint, retain all records,
and analyze a genuinely different justified hypothesis; no automatic seed retry,
longer training, threshold relaxation or GDF addition to obtain a positive.
Exact source/hash/runtime/input and natural-exit evidence must accompany all results.

本目录保存客观标量和可重绘曲线，便于独立检查训练过程。它对应固定的 **ratio-r2 局部适配研究**，源码提交为 `beab40c2b63345336c2eda8556d0caf99abad7f7`，seed 为 `20261032`。新版 `gdf-joint-r3` 使用独立运行及结果目录，不把旧记录改名为新版结果。

主线 AR_GDF 的七阶段已完成；C0、AR、C0_GDF 的导出只包含快照时实际存在的记录。尚未产生的阶段、验证点和原生整例端点不补零、不插值。目录中的快照元数据说明各阶段实际覆盖的更新范围及完成状态；后续快照会按相同定义更新。

本次采集窗口为 **2026-10-28 10:22:13—10:24:11 UTC**，对应北京时间 **18:22:13—18:24:11**。不同分支各自的准确采集时刻保留在导出元数据中；这不是同一时刻冻结所有运行的原子快照。

还保留 `original_P_control`：这是比例BCE修订前完整执行30k的原始属性预训练对照，仅有P阶段，源提交为 `1106e7e52ad0114cc0c4bcbcfaf824b9c2236fe0`。其后续分割入口被有意阻止，不能把这件事写成P训练失败，也不能将其与AR_GDF一起计算分割训练预算。两次P预训练的损失配方不同，原始总loss不宜直接比较数值高低；它是属性训练配方记录，不是有P／无P的独立分割消融。图2仅画实际主线使用的ratio-r2 P预训练，原始P对照的全部导出指标保留在CSV中。

训练点按成功更新间隔抽取；验证点及AMP跳过事件另外完整保留。精确抽样间隔、原日志覆盖范围、是否含完整逐步记录、输入日志摘要和输出文件摘要以导出元数据为准。不能由稀疏训练CSV恢复未导出的所有逐步波动，也不能把窗口均值当作某一次真实训练批次。

本次训练原始标量的抽样间隔为100次成功更新，另保留首末记录。导出包含2,063个训练标量点、32,320行窗口指标、194个验证汇总点、1,952行验证病例记录、17行阶段终点及2个核验过的选择点。AMP表有107行，含阶段总计与间隙记录，**不是107次溢出**；原日志没有记录失败批次的损失或输入身份，不能凭此重建它们。

## 列名与单位

- `run_label`：实验分支名称。`AR_GDF` 是本轮旧版主线；`C0`、`AR`、`C0_GDF` 是其配对局部适配分支。C0保留P和属性特征融合，仅使用可学静态条件门。
- `phase`：`attribute`、`base_warm`、`base`、`condition`、`gdf_head`、`geometry`、`refine`。
- `successful_update`：阶段内成功的优化器更新数。`attempt` 是尝试数；AMP溢出导致的跳过不计成功更新。两者不能混用。
- `losses.*`：原始记录的损失值。`primary_segmentation_loss` 为实际加权的主分割项，`gdf_mse` 为未乘几何倍率的场误差，`weighted_gdf_loss` 为实际加权项；前景和背景GDF误差单列。
- `learning_rates.*`：原始优化器组学习率；不同阶段重新建立优化器。`alpha` 为条件适配强度，`gdf_weight` 为几何项倍率。
- `summary.*`、`attributes.summary.*`：原记录的指标及统计。CSV中的Dice、precision、recall等通常为 `[0,1]` 分数；图中明确乘100显示为百分数。标准化log半径MSE不是毫米误差。
- `sampling.*`：实际取块、回退、前景比例等记录。取块来源比例与前景体素比例是两种不同数量；原始比例分数不自动乘100。
- 空字段或JSON `null` 表示该项未记录、未定义或不适用，不能视为0。

原始日志没有逐次更新的耗时就保留为空，不由平均吞吐量倒推出伪造的逐步时间戳。阶段总耗时与快照采集时间是不同字段。

## 训练阶段与横轴

| 阶段 | 预算 | 优化范围 |
|---|---:|---|
| 属性预训练 | 30k | P |
| 底座建立 | 20k | P与S，中性条件 |
| 底座长训练 | 30k | P与S，中性条件 |
| 条件适配 | 10k | P及底座主干固定，局部路由、形态分支、融合和分割输出 |
| 高斯头预热 | 2k | 仅高斯头，S固定 |
| 局部几何强化 | 20k | 旧版局部适配范围 |
| 平衡微调 | 10k | 同一局部范围，较低学习率 |

主线总计算预算122k含30k仅P预训练和2k仅高斯头预热。图1的横轴为**不含P预训练的执行流程更新数**，共92k，不能称为92k次S更新。

所选底座为热身20k后的 `base` 第27k检查点，S权重谱系为47k；随后条件阶段从它继承。执行完30k底座预算与实际所继承权重经过27k，是两件不同的事。跨阶段图示坐标记录已执行计算，不把被选择过程舍弃的后3k更新算入后续权重谱系。

不同阶段的总损失含有不同监督项，跨阶段总loss的跳变不能直接解释为优化进步。图中不会将相邻阶段的训练线跨边界连接，也不会把头预热期间的分割诊断值当作S正在学习。

## 评价口径与结果边界

固定验证为8例×每例8个128³区块。先对每例的区块指标平均，再对8例等权平均。它不是整例预测，也不是将所有区块体素合并后计算Dice。全空真值区块的Dice约定会使平均值对极少量误检敏感，详细定义见对应指标代码及原始记录。

P的支撑Dice是属性预测质量；S的区块Dice是分割过程指标；原生整例Dice是最终病例预测指标。这三者分别保存，不能直接相减或替代。

原生整例指标见[独立客观端点记录](../v12_core_native_20261028_partial/README.md)。F位于条件及GDF之前；F到最终AR_GDF包含额外42k流程，不能作为仅增加GDF的因果对照。其他分支尚未完成时不报告完整2×2结论。

高斯MSE、路由幅度和条件门变化是过程量，不单独证明分割、连通性或动态条件收益。此目录保留客观数值，不包含主观方法结论、凭据、私有部署路径、原始影像或标注，也不包含模型权重。
